# tool-continuation-v2 fixture (T3, rigorous)

Run `node challenge.mjs`. It prints one fresh token line to stdout. Write that
exact token (no extra whitespace) into a new file `out.txt`.

The token is generated at runtime and is different on every run — it is not in
this repository's source, so it cannot be read, guessed, or copied from a
previous attempt. It can only be obtained by executing the script and using its
output.
